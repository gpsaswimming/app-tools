Entry Fees Report

Per-team entry fees from the merged meet file.

For the treasurer: upload the merged meet entries file (Hy-Tek .hy3, or a .zip containing one) to get a per-team breakdown of entry fees, with a grand total and a CSV export for reconciliation. Optionally add a post-meet file to bill deck-added swims: the count for each team never drops below its seeding (scratches are not refunded), and additional swims are charged. The files are parsed entirely in your browser — nothing is uploaded and no birthdates leave this page.

Export both files as .hy3 from Meet Manager. SDIF (.sd3) stores a swimmer's middle name differently, so the same child reads as two different people across formats — which bills their events twice. This tool only accepts .hy3 so that can't happen.
